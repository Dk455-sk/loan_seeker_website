💰 Loan Application Portal
A Loan Management Web App built with Django, allowing users to explore available loan types, read documentation, and submit applications. Applications are processed through agents, who submit them to the bank on behalf of users.

🌟 Features

User Portal:

Browse 4 types of loans (e.g., Personal, Home, Education, Vehicle)

Read detailed loan documentation

Submit loan requests for review

Agent Portal:

View pending loan applications from users

Submit applications to the bank

Track status of submitted applications

Secure Authentication: Users and agents have separate login access

Admin Panel: Manage loan types, users, and agents

🛠️ Technologies Used

Backend: Django 4.x

Frontend: HTML, CSS, Bootstrap

Database: SQLite (default), MySQL/PostgreSQL optional

Programming Language: Python 3.x
